# SysControl

Sistema offline de controle de materiais e serviços para o setor de manutenção, desenvolvido em HTML, CSS e JavaScript puro, com armazenamento local via `LocalStorage`.

## Sobre o projeto

O SysControl foi criado para substituir o controle manual de materiais e serviços de um setor de manutenção elétrica/mecânica, oferecendo:

- Cadastro, edição e exclusão de materiais
- Controle de quantidade e custo unitário, com cálculo automático de total
- Dashboard inicial com resumo do setor
- Funcionamento 100% offline — sem necessidade de servidor ou internet

## Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
- LocalStorage (persistência de dados no navegador)

## Como usar

1. Clone o repositório:
   ```
   git clone https://github.com/UriellBarbosa/syscontrol.git
   ```
2. Abra a pasta do projeto no VS Code (ou editor de sua preferência).
3. Abra o arquivo `index.html` no navegador — recomenda-se usar a extensão **Live Server** do VS Code para melhor experiência.
4. Pronto! O sistema já pode ser utilizado, sem necessidade de instalação de dependências.
